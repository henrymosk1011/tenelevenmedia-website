# Working in this repo

## Shipping changes

When asked to make a change, finish it by opening a pull request into `main` and merging it right away. Don't stop to ask whether to open the PR or merge it. GitHub Pages publishes the site from `main`, so a change isn't live until it's merged.

Check the work before merging (load the site locally and confirm the change renders with no console errors), since merging publishes it.

See `README.md` for how the site, the project list and the screenshot script work.
